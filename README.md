# python_basic
Basic python exercises for initial training# Python Basic Learning Repository

Welcome to the **Python Basic Learning Repository**! This repository is designed for beginners who want to practice fundamental Python concepts through three interactive exercises. Each module focuses on key programming principles such as data validation, loops, conditional logic, and functions.

## Repository Structure

```
python_basic/
│── LICENSE
│── README.md
│── module-one/   # Product Validation System
│── module-two/   # Grade and Statistics Challenge
│── module-three/ # Inventory Management System
```

Each module contains a standalone Python script with a well-documented solution. The scripts are written with detailed comments in English, making them easy to understand and modify.

## Exercise Descriptions

### **Module One: Product Validation System**
- **Objective:** Calculate the total cost of a purchase based on product price, quantity, and discount.
- **Concepts Covered:**
  - User input validation (ensuring numeric inputs are correct)
  - Arithmetic operations (applying discounts)
  - String handling (formatting output properly)
- **How to Run:**
  ```sh
  cd module-one
  python product_validation.py
  ```

### **Module Two: Grade and Statistics Challenge**
- **Objective:** Analyze student grades by determining pass/fail status, calculating averages, and counting occurrences.
- **Concepts Covered:**
  - Conditional statements (if-else logic for pass/fail evaluation)
  - Loops (for and while for data processing)
  - Functions (structured approach to data handling)
- **How to Run:**
  ```sh
  cd module-two
  python grades_statistics.py
  ```

### **Module Three: Inventory Management System**
- **Objective:** Manage an inventory system that allows adding, updating, searching, and deleting products.
- **Concepts Covered:**
  - Dictionaries and lists (storing product information)
  - Functions with return values (structured inventory operations)
  - Lambda functions (calculating total inventory value)
- **How to Run:**
  ```sh
  cd module-three
  python inventory_management.py
  ```

## Requirements
- Python 3.x installed
- Basic knowledge of Python syntax
